# 상담이력(2025년 1·2월) 스키마 / 정제 로그

## 개요

기존 [[data_consultations]](2024년 1~12월, 1,320건, `consult_date` 최대 2024-12-31)의 바로 다음 구간인 2025년 1·2월 CS 상담 이력. 실제 반출이 막혀 있어 기존 스키마·값 체계·[[data_agents]]의 AG01~AG20/1~3팀 구조를 그대로 반영한 합성(synthetic) 데이터로 대체 확보했다. 원본은 월별 시트(엑셀 인쇄용 리포트 형태, 팀 병합 셀 + 소계 행 + 혼합 서식 혼재)라 그대로는 분석에 쓸 수 없어 [[clean_상담이력]](이 폴더에 함께 저장된 스크립트)로 정제했다.

## 컬럼 정의 표 (정제 후 개인 테이블 기준)

| 컬럼명 | 타입 | 의미 |
|---|---|---|
| 년월 | STRING | 원본 시트명(`2025-01`/`2025-02`) |
| 소속 | STRING | 소속 팀(1~3팀). 원본은 병합 셀이라 forward-fill로 복원함 |
| 담당자 | STRING | 상담원 ID(AG01~AG20), [[data_agents]]와 연결 |
| 고객번호 | STRING | 고객 ID(C001~C500), [[data_customers]]와 연결 |
| 상담일 | DATE | 원본에 표준/점표기/엑셀 일련번호 3가지 형식이 섞여 있어 통일함 |
| 채널 | STRING | 전화/채팅/이메일/앱 |
| 문의유형 | STRING | 요금문의/해지문의/장애신고/부가서비스/기타/명의변경 |
| 상담시간 | FLOAT | 분 단위. 원본에 "N분" 문자열과 숫자가 섞여 있어 통일함. 결측 존재(임의로 채우지 않음) |
| 처리결과 | STRING | 완료/미해결/재문의 |
| 재문의여부 | BOOLEAN | 원본은 텍스트가 아니라 배경색(빨강=True)으로만 표시된 경우가 있어, 색상 기준으로 변환함 |

## 정제 규칙 요약

원본 5가지 구조 문제와 처리 규칙(무엇/왜/순서 상세는 홈 디렉토리 `정제_규칙_상담이력.md` 참고):

1. **소속(A열) 병합 셀 forward-fill**
2. **상담일 형식 통일** — 표준/점표기/엑셀 일련번호 → date
3. **상담시간 형식 통일** — "N분" 문자열/숫자 → 숫자
4. **재문의여부 배경색 변환** — 빨간 배경 → True, "N" 텍스트 → False
5. **소계 행 분리** — 팀 소계 행을 개인 테이블에서 제외하고 별도 팀 요약 테이블로 분리

## 정제 로그

### 정제 전/후 행 수

| 구분 | 행 수 |
|---|---|
| 정제 전(시트 2개 × 데이터 110행 + 소계 3행) | 시트당 113행 |
| 정제 후 — 개인 테이블 | 220행 |
| 정제 후 — 팀 요약 테이블 | 6행(팀 3 × 월 2) |

### 상담시간 검증

- 개인 테이블에서 년월·소속별로 재계산한 상담시간 합계가 팀 요약 테이블의 `상담시간_합계`와 6개 조합 전부 정확히 일치(불일치 0건)

### 스크립트 품질 검증

- **멱등성**: 동일 입력으로 스크립트를 2회 연속 실행 → 개인 테이블 CSV, 팀 요약 CSV 모두 MD5 완전 일치
- **안전장치**: 재문의여부가 "N" 텍스트도 빨간 배경도 아닌 경우 스크립트가 예외를 던지도록 함(실제 데이터 220건 전부 예외 없이 처리됨)

## 비고 — 아직 남은 확인 필요 사항

정제로 해결되지 않는 구조적 모호함:

- 행 고유 식별자(`consult_id` 같은 PK)가 없어 완전 중복 행 구분 불가
- "상담일"이 접수일/진행일/완료일 중 무엇인지 불명
- "재문의여부"가 이 상담이 과거 상담의 재문의인지, 이 상담 이후 재문의가 발생했는지 방향성 불명(기존 [[data_consultations]]의 `is_recontact`도 동일한 모호함을 가짐)
- 이 노트는 정제 완료 후 결과를 기록한 것이며, `raw/` 정식 편입은 별도 단계로 남아있음
- 원본 엑셀 파일은 이번 정제 과정에서 한 번도 수정되지 않았음
