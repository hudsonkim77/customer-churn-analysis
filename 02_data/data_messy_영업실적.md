# 영업실적(3월 실적) 스키마 / 정제 로그

## 개요

영업팀 3월 실적을 담은 Excel 리포트(시트 "3월 실적", 원본 15행 5열). CS 5종 데이터와는 도메인이 다른 영업 실적 데이터로, `raw/`에는 아직 정식 편입되지 않았다. 원본은 Excel 인쇄용 리포트 형태(병합 셀 + 소계 행 혼재)라 그대로는 분석에 쓸 수 없어 [[clean_영업실적]](이 폴더에 함께 저장된 스크립트)로 정제했다.

## 컬럼 정의 표 (정제 후 개인 테이블 기준)

| 컬럼명 | 타입 | 의미 |
|---|---|---|
| 소속팀 | STRING | 소속 팀. 원본은 병합 셀이라 forward-fill로 복원함 |
| 담당자 | STRING | 담당 영업사원 이름. 원본에는 "N팀 소계" 행도 같은 컬럼에 섞여 있었음(분리됨) |
| 계약건수 | INTEGER | 월 계약 건수 |
| 매출액 | STRING(콤마 포맷) | 매출액(원). "원" 단위만 제거, 콤마 표기는 유지(예: `76,380,000`) |
| 목표달성률 | FLOAT | 목표 대비 달성률. 소수로 통일(예: `112%` → `1.12`) |

## 정제 규칙 요약

원본 3가지 구조 문제와 처리 규칙(무엇/왜/순서 상세는 홈 디렉토리 `정제_규칙_영업실적.md` 참고):

1. **병합 셀 채우기** — `소속팀`이 병합 셀이라 첫 행에만 값이 있던 것을 forward-fill로 복원
2. **텍스트→숫자 변환** — `매출액`(콤마 유지, "원" 제거), `목표달성률`("%" 제거 후 소수화)
3. **소계 행 분리** — `담당자`가 "소계"로 끝나는 행을 개인 테이블에서 제외하고 별도 팀 요약 테이블로 분리

## 정제 로그

### 정제 전/후 행 수

| 구분 | 행 수 |
|---|---|
| 정제 전(원본) | 15행 |
| 정제 후 — 개인 테이블 | 12행 |
| 정제 후 — 팀 요약 테이블 | 3행 |
| 검산(12+3=15) | 일치 |

### 매출액 검증

- 정제 후 개인 테이블 매출액 합계: **711,760,000**
- 팀별 소계(1팀 222,220,000 + 2팀 186,990,000 + 3팀 302,550,000) 합계와 정확히 일치 → 정제 과정에서 값 손실·중복 없음 확인

### 스크립트 품질 검증

- **멱등성**: 동일 입력(`data_messy_영업실적.xlsx`)으로 스크립트를 2회 연속 실행 → stdout, 개인 테이블 CSV, 팀 요약 CSV 모두 MD5 완전 일치
- **일반화(하드코딩 여부)**: 3팀 데이터를 복제해 "4팀"을 추가한 테스트 파일(21행, 병합 셀 포함)로 실행 → 정제 후 개인 17행·팀 요약 4행·매출액 합계 1,014,310,000으로 팀 수 증가에 정상 대응(팀 수·행 수를 코드에 하드코딩하지 않았음을 확인)

## 비고

- 이 노트는 정제 완료 후 결과를 기록한 것이며, `raw/` 정식 편입([[data_retention_campaign]]과 같은 "아직 미편입" 상태)은 별도 단계로 남아있음.
- 원본 엑셀 파일은 이번 정제·테스트 과정에서 한 번도 수정되지 않았음(스크립트 자체에 출력 경로 충돌 시 중단하는 안전장치 포함).
